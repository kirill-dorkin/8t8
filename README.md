# SHIP7

A lean validation project for a paid 7-day full-stack build sprint.

## Live product

This repository contains the production landing page (`index.html`) and a GitHub Pages deployment workflow.

**Offer:** ship your first real full-stack app in 7 days.  
**Founding price:** $25 one-time.  
**Audience:** beginners who know basic JavaScript but are stuck in tutorial hell.

## Funnel

TikTok / Reels / Shorts → landing page → `Reserve founding access` → demand validation → payment → record the first lessons.

The current CTA intentionally does **not** charge anyone. It opens a GitHub request so demand can be measured before spending weeks recording a course.

## Files

- `index.html` — landing page.
- `content-plan.md` — 12 ready-to-film short-video scripts and filming rules.
- `LAUNCH.md` — exact 48-hour launch checklist and kill/pivot signals.
- `.github/workflows/pages.yml` — automatic GitHub Pages deployment.

## Product rule

Do not build an LMS, AI tutor, community, mentoring team or long curriculum before demand is proven. Get 3–5 strong purchase-intent signals first.

Deployment is configured to publish automatically from `main`.

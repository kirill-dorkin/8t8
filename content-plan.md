# SHIP7 — что снимать

Цель контента: не учить программированию целиком, а поймать человека в состоянии «я смотрю туториалы, но ничего не закончил» и отправить на лендинг.

## Формат каждого ролика

- 15–30 секунд.
- 9:16, 1080×1920.
- Первые 1–2 секунды: крупный текст-хук.
- 70–80% экрана: запись экрана VS Code / браузера.
- Голос: английский. Если не хотите светить лицо — вообще не нужно.
- Субтитры: английские, крупные.
- Аниме-персонаж: маленький оверлей в углу, не больше 15–20% экрана. Это упаковка, а не смысл ролика.
- CTA последних 2 секунд: `Build your first full-stack app in 7 days — link in bio.`

## Снимать сегодня: первые 6 роликов

### 1. Tutorial hell
**Текст на экране:** `You don't need another 12-hour coding course.`

**Кадр:** быстро пролистать длинный YouTube-курс, затем переключиться на работающий маленький web app.

**Voice-over:**
> You don't need another twelve-hour course. You need one small app, one deadline, and a reason to finish. That's why I built a seven-day full-stack sprint.

**CTA:** `Ship something real. Link in bio.`

### 2. From blank folder to live app
**Текст:** `Blank folder → live app in 7 days.`

**Кадр:** пустая папка → VS Code → localhost → финальный deployed app.

**Voice-over:**
> Day one starts with a blank folder. Day seven ends with a live link you can actually put in your portfolio. No endless theory in between.

**CTA:** `See the 7-day plan.`

### 3. Why beginners stay stuck
**Текст:** `Why you still can't build alone:`

**Кадр:** три быстрые надписи поверх кода: `too many tutorials`, `no project scope`, `no deadline`.

**Voice-over:**
> Most beginners are not stuck because they're stupid. They're stuck because every tutorial gives them another topic instead of one finished project.

**CTA:** `Build one project. Link in bio.`

### 4. Full-stack explained in 20 seconds
**Текст:** `Full-stack in 20 seconds.`

**Кадр:** браузер → API request → database → response.

**Voice-over:**
> The frontend sends a request. Your backend decides what to do. The database stores the result. Then the user sees it. That's the loop we're building in SHIP7.

**CTA:** `Learn it by building it.`

### 5. Stop copying code
**Текст:** `Copying code feels productive. It isn't.`

**Кадр:** copy/paste snippet → ошибка → затем маленькая схема потока данных.

**Voice-over:**
> If you copy twenty files and the app works, you learned almost nothing. Build smaller. Understand the data flow. Then add the next piece.

**CTA:** `7 missions. 1 finished app.`

### 6. Day 3 teaser
**Текст:** `Day 3: your app gets real data.`

**Кадр:** таблица базы данных + создание записи из интерфейса.

**Voice-over:**
> This is the moment a toy frontend becomes a real app. Submit the form, store the data, refresh the page — it's still there.

**CTA:** `SHIP7 — link in bio.`

## Как монтировать

1. Screen recording: OBS или встроенная запись экрана.
2. Монтаж: CapCut.
3. Удаляете все паузы.
4. Автосубтитры → вручную исправить 2–3 ошибки.
5. На первом кадре 4–8 слов крупным шрифтом.
6. Никаких интро, логотипов и «Hey guys».
7. Каждый ролик заканчивается одним CTA.
8. Один исходник публикуйте в TikTok, Reels и Shorts без водяного знака.

## Ритм теста

- День 1: ролики 1, 2, 3.
- День 2: ролики 4, 5, 6.
- День 3: переснять лучший хук в 3 вариантах.
- Дни 4–7: по 2 ролика в день.

Не судить идею после 2–3 роликов. Сначала выпустить минимум 12–15 коротких видео и смотреть на переходы по ссылке и заявки.
